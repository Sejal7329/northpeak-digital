# 🏔️ NorthPeak Digital — Agency Landing Page

A modern, fast, and fully responsive single-page application (SPA) built for **NorthPeak Digital**, a fictional digital agency. Designed with a clean UI, smooth navigation, and optimized for performance and accessibility.

Live Demo: [Insert Your Vercel / Netlify Link Here]

---

## ✨ Features

- **Responsive Header & Navigation:** Sticky glassmorphism header with a mobile hamburger navigation menu.
- **Hero Section:** Engaging headline, call-to-action (CTA) buttons, and custom visual cards.
- **Services Showcase:** Grid layout featuring 6 core agency service offerings.
- **Featured Projects (Portfolio):** 6 client showcase cards with hover states, direct links, and dynamic tags.
- **Transparent Pricing:** 3 tier pricing plans with a highlighted "Most Popular" plan.
- **Interactive Contact Form:** Built-in React state client-side validation (email format checking, required fields, and success state).
- **Mandatory Verification Credit:** Footer link integrated for Digital Heroes training task verification.

---

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Styling:** CSS3 (Flexbox & CSS Grid, Custom Media Queries)
- **Icons:** React Icons (`react-icons/fa`)
- **Deployment:** Vercel / GitHub Pages

---

## ⚡ Performance & Accessibility Highlights

- **Lighthouse Score:** 90+ across Performance and Accessibility.
- **Semantic HTML:** Fully structured with `<header>`, `<main>`, `<section>`, `<article>`, and `<footer>` tags.
- **Optimized Assets:** Responsive image loading (`loading="lazy"`) with explicit dimensions to prevent Content Layout Shift (CLS).
- **High Contrast:** Color palette designed to meet WCAG AA standards.
